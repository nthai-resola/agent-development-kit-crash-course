# Project Brief: Agent Development Kit Crash Course

## Overview
This project is a crash course on building AI agents using the Agent Development Kit. It consists of multiple examples demonstrating different agent capabilities, from basic to advanced implementations.

## Core Requirements
- Provide practical examples of agent implementations
- Demonstrate progressive complexity in agent development
- Show various agent patterns (basic, tool-using, stateful, multi-agent, etc.)
- Enable developers to understand and build their own agents

## Goals
- Create a comprehensive learning resource for agent development
- Demonstrate best practices in agent architecture
- Provide working code examples that can be extended
- Show the evolution from simple to complex agent patterns

## Project Scope
The project covers multiple agent implementations, organized in numbered folders from basic to advanced:
1. Basic agent implementation
2. Tool-using agents
3. LiteLLM integration
4. Structured outputs
5. Sessions and state management
6. Persistent storage
7. Multi-agent systems
8. Stateful multi-agent systems
9. Callbacks
10. Sequential agents
11. Parallel agents
12. Loop agents

Each example builds on concepts from previous examples, creating a learning path for agent development.
